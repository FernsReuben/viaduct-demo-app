# Viaduct Demo App

Frontend prototype/mockup exploring onboarding, group management,
and identity orchestration workflows for a Viaduct-style platform.

Current focus:
- onboarding UX
- group and permission management
- provisioning workflow visualization
- integration concepts for:
  - Google Workspace
  - GitHub
  - Discord

This prototype currently uses seeded/mock data and is intended
for workflow exploration and UI design rather than production
authorization or provisioning infrastructure.

## Run locally

```bash
npm install
npm run dev
